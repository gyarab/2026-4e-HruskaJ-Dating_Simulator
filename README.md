# 2026-4e-HruskaJ-Dating_Simulator
Cílem projektu je vytvoření klikací příběhové hry typu dating simulator (vizuální novela). Hráč se v roli hlavní postavy štěpí v příběhu pomocí dialogových voleb a interaktivních rozhodnutí, které přímo ovlivňují vývoj vztahů s ostatními postavami a vedou k různým možným koncům (Good/Bad Ending).
